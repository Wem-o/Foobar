# FooBar is a bar / shell for Wayland*

-# *: As you've probably read a billion times, Wayland is just a protocol. This project supports most
popular wayland compositors implementing wlr layershell.

FooBar aims to be a somewhat customizable, fast and "works out of the box" bar and shell. It prioretizes power users, with keyboard first design.
